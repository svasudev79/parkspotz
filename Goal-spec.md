## 1. Problem Statement
<!-- What problem does this app solve? Who has this problem today, and how do they cope without this tool? -->
- Parking discovery in Bangalore is at best fragmented and there is no publicly available app for paid booking parking ahead before reaching a destination place. 
- This is specifically trying to address car parking spaces. Support for bike parking will be done in Phase2 
- This is an attempt to democratize the parking discovery and ease reaching a destination without worrying for parking.


## 2. Target Users
<!-- Who uses this app? e.g. solo travelers, families, groups of friends. Include any relevant personas. -->
Target metro users who can park their cars, families going out to dinner, early Sunday morning trips within the city and be able to park in legal spaces and not worry about no-parking zones.  
Also target parking space owners to be able to have a simple app to be able to list their space for parking and hassle free rent out or manage parking. 
The parking space can be rented by the owner of the space and owner manages it. 
Phase2: In another business model the parking app (ParkspotZ) will be renting out the space and manage the parking space.
Phase2: In case of managed parking spaces by ParkSpotZ, it will be able to differentiate by listing number of spots available, physical security, clean surfaces, restroom facilities.

## 3. Core Use Cases
<!-- The primary user journeys, as short scenarios. e.g. "As a user, I want to create a trip and add destinations so that I can see my itinerary in one place." -->
- Phase1: As a user, search end destination, see nearest available parking space, book the slot with time/date and duration details and pay for it.
- Phase1: As a user once paid be able to get and save a receipt with unique QR code and also lists the details of the parking.
- Phase1: As a parking space owner, should be able to list the parking space and run day to day operations like being able to charge 

## 4. Core Features (MVP)
<!-- Bullet list of must-have features for v1. Be specific enough to scope work, not exhaustive. -->
- Responsive web application (usable on both desktop and mobile browsers \'97 no native mobile app)
- Users can sign up (username + password) and log in through login/signup screens
- Users should be able to list all parking spaces available near a particular destination in a map interface and a list interface. Radius of search for parking space should be available. 
- Parking space owners should be able to monitor day, week, month usage statistics along with revenue from renting parking slots. 
- Be able to onboard parking space with number of slots, price , start and close times per day
